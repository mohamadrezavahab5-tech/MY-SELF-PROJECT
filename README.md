# پاسخ‌یار — چت‌بات پاسخگوی فارسی برای کسب‌وکارها

یک سرویس آنلاین (SaaS) که هر کسب‌وکار یا سازمانی در آن ثبت‌نام می‌کند، سؤال و جواب‌هایش را وارد می‌کند و با گذاشتن یک خط کد در سایتش (یا وصل کردن ربات بله)، یک چت‌بات ۲۴ ساعته دارد.

**مدل درآمد:** اشتراک ماهانه، سه‌ماهه یا سالانه (پلن‌های حرفه‌ای و سازمانی) با درگاه زرین‌پال.
**رشد خودکار:**
- روی بات کاربران رایگان لینک «قدرت‌گرفته از پاسخ‌یار» هست.
- هر کاربر یک لینک معرفی دارد و از هر پرداخت مشتری‌هایی که معرفی کرده، ۲۵٪ پورسانت می‌گیرد.

## امکانات

- **موتور جستجوی فارسی:** بدون هوش مصنوعی خارجی، روی سرور خودتان اجرا می‌شود و فارسی محاوره‌ای و غلط تایپی را می‌فهمد.
- **ویجت چت:** قابل نصب روی هر سایتی، یک صفحه‌ی گفتگوی اختصاصی (`/c/...`) و ربات بله (و تلگرام، اگر سرور خارج از ایران باشد).
- **صندوق «سؤال‌های بی‌جواب»:** بات هر سؤالی را که بلد نبوده جمع می‌کند و صاحب کسب‌وکار با یک کلیک جوابش را می‌دهد تا دفعه‌ی بعد خود بات جواب بدهد.
- **گرفتن شماره‌ی مشتری:** وقتی بات جواب را نمی‌داند، نام و شماره‌ی مشتری را می‌گیرد.
- **ورود خودکار از سایت مشتری:** مشتری فقط آدرس صفحه‌ی «سؤالات متداول» سایتش را می‌دهد و سؤال و جواب‌ها خودکار استخراج می‌شوند (از اسکیمای Yoast/Rank Math، آکاردئون‌ها، المنتور و تیترها).
- **بسته‌های سؤال و جواب آماده** برای ۱۲ صنف، به‌علاوه‌ی ورود از اکسل، CSV یا متن.
- **نسخه‌ی سازمانی (نصب روی سرور سازمان):** صفحه‌ی `/enterprise` با فرم درخواست دمو. درخواست‌ها در پنل مدیریت نمایش داده می‌شوند. این همان پیشنهاد گران‌قیمت برای ادارات، بانک‌ها و بیمه‌هاست.
- **پرداخت:** زرین‌پال، با کد تخفیف خودکار برای کسانی که با لینک معرفی آمده‌اند.
- **همکاری در فروش:** پورسانت برای معرفی‌کننده، درخواست تسویه با شماره‌ی شبا و پنل مدیریت.
- **سئو:** صفحه‌های مخصوص هر صنف، ۱۲ صفحه‌ی «نمونه سؤالات متداول» برای هر صنف (کلمه‌هایی که صاحبان کسب‌وکار جستجو می‌کنند)، مجله، sitemap، داده‌های ساختاریافته (JSON-LD) و متاتگ‌ها.

## اجرا روی کامپیوتر خودتان

به Node.js نسخه‌ی ۲۲٫۱۳ یا بالاتر نیاز دارید.

**ویندوز، ساده‌ترین راه:** نسخه‌ی LTS را از nodejs.org نصب کنید و روی فایل `start-windows.bat` دو بار کلیک کنید. سایت در مرورگر باز می‌شود (`http://localhost:3000`) و حساب نمونه هم مدیر سایت است. تا وقتی از سایت استفاده می‌کنید، پنجره‌ی سیاه را نبندید.

```bash
npm install
npm run seed   # یک حساب نمونه می‌سازد: 09120000000 / demo1234
npm start      # http://localhost:3000
npm test       # تست‌های خودکار
npm run eval   # سنجش دقت موتور جستجو
```

در حالت توسعه، پرداخت‌ها «آزمایشی» هستند و پولی جابه‌جا نمی‌شود.

## دیدن سایت داخل گیت‌هاب (Codespaces)

بدون نصب هیچ چیز روی کامپیوتر:

1. در صفحه‌ی مخزن روی دکمه‌ی سبز **Code** بزنید، زبانه‌ی **Codespaces** را باز کنید و **Create codespace** را بزنید. اگر هنوز Merge نکرده‌اید، اول شاخه‌ی `claude/focused-gates-kjhaf4` را انتخاب کنید.
2. چند دقیقه صبر کنید تا آماده شود. سایت خودکار اجرا می‌شود و در یک زبانه‌ی جدید باز می‌شود. اگر باز نشد، پایین صفحه زبانه‌ی **Ports** را باز کنید و کنار پورت 3000 روی آیکون کره‌ی زمین بزنید.
3. ورود با حساب نمونه: `09120000000` و رمز `demo1234`. این حساب مدیر سایت هم هست (`/admin`).

این نسخه فقط برای دیدن و امتحان است و وقتی Codespace خاموش شود، سایت هم خاموش می‌شود. آدرسش هم فقط برای خود شما باز می‌شود. برای سایت واقعی و همیشه‌روشن، بخش لیارا را ببینید.

## راه‌اندازی آنلاین (پیشنهاد: لیارا)

۱. در [liara.ir](https://liara.ir) حساب بسازید و یک برنامه‌ی **NodeJS** ایجاد کنید. نسخه‌ی Node را **۲۲** انتخاب کنید.

۲. در بخش **دیسک‌ها** یک دیسک (مثلاً ۱ گیگابایت) بسازید و آن را به مسیر `/data` وصل کنید. دیتابیس اینجا ذخیره می‌شود و با هر بار آپدیت پاک نمی‌شود.

۳. در بخش **متغیرهای محیطی** این‌ها را بگذارید (فهرست کامل در `.env.example` است):

| متغیر | مقدار |
|---|---|
| `NODE_ENV` | `production` |
| `SITE_URL` | آدرس سایت با https، مثلاً `https://pasokhyar.ir` |
| `DATA_DIR` | `/data` |
| `ADMIN_PHONES` | شماره موبایل خودتان (برای پنل مدیریت) |
| `ZARINPAL_MERCHANT` | مرچنت‌کد زرین‌پال (وقتی گرفتید) |

۴. برنامه را از طریق اتصال GitHub همین ریپازیتوری یا با `liara deploy` مستقر کنید.

۵. دامنه را در بخش **دامنه‌ها** وصل کنید و SSL را فعال کنید.

۶. با همان شماره‌ای که در `ADMIN_PHONES` گذاشتید ثبت‌نام کنید. پنل «مدیریت سایت» در داشبورد برایتان ظاهر می‌شود.

> روی هر سرور دیگری که Docker دارد (هم‌روش، ابر آروان یا VPS) هم می‌توانید از `Dockerfile` استفاده کنید. فقط پوشه‌ی `/data` باید دائمی باشد.

## درگاه پرداخت زرین‌پال

۱. در [zarinpal.com](https://www.zarinpal.com) ثبت‌نام کنید و احراز هویت را کامل کنید.
۲. یک «درگاه پرداخت» برای دامنه‌ی سایتتان درخواست بدهید. معمولاً صفحه‌های قوانین، حریم خصوصی و تماس لازم است که سایت همه‌شان را دارد. ممکن است **اینماد** هم بخواهند.
۳. مرچنت‌کد را در متغیر `ZARINPAL_MERCHANT` بگذارید و برنامه را ری‌استارت کنید.
۴. برای تست قبل از پرداخت واقعی، `PAYMENT_MODE=sandbox` بگذارید.

تا وقتی مرچنت‌کد وارد نشده، دکمه‌های پرداخت در سایت «به‌زودی» نشان داده می‌شوند و بقیه‌ی سایت کامل کار می‌کند.

**اینماد:** بعد از گرفتن دامنه، از [enamad.ir](https://enamad.ir) درخواست بدهید. کد نشان اینماد و زرین‌پال را در `TRUST_BADGES_HTML` بگذارید تا در فوتر نمایش داده شود.

## سئو: کارهایی که بعد از راه‌اندازی باید انجام دهید (یک‌بار)

۱. سایت را در [Google Search Console](https://search.google.com/search-console) ثبت کنید و آدرس `https://دامنه/sitemap.xml` را Submit کنید.
۲. همین کار را در Bing Webmaster Tools هم انجام دهید.
۳. تصویر `public/img/og.png` همان تصویری است که موقع اشتراک‌گذاری لینک نمایش داده می‌شود.

مقاله‌های مجله در `src/content/blog.js` هستند. هرچه مقاله‌ی مفید بیشتری اضافه شود، ورودی گوگل بیشتر می‌شود.

## واقعیت سئو (صادقانه)

سئوی فنی کامل انجام شده است: سرعت بالا (بدون فایل خارجی)، sitemap، اسکیما، متاتگ‌ها، لینک‌سازی داخلی و ۴۰ صفحه‌ی محتوایی. با این حال:

- کلمه‌های کلی مثل «چت بات» و «چت آنلاین» دست رقبای قدیمی است (رایچت، گفتینو و…). سایت تازه برای آن‌ها ماه‌ها طول می‌کشد.
- استراتژی ما **کلمه‌های دُم‌بلند** است که رقبا رهایشان کرده‌اند: «چت بات کلینیک»، «نمونه سوالات متداول فروشگاه اینترنتی»، «ربات پاسخگوی بله» و مانند این‌ها. این‌ها معمولاً در ۱ تا ۳ ماه بعد از ایندکس شدن بالا می‌آیند.
- مهم‌ترین عامل بعدی **بک‌لینک** است: از سایت‌هایی که مقاله‌ی «بهترین افزونه‌های چت آنلاین» دارند بخواهید شما را هم معرفی کنند. به طراح‌های سایت هم برنامه‌ی همکاری در فروش را پیشنهاد بدهید.
- هر ماه دو سه مقاله‌ی تازه به `src/content/blog.js` اضافه کنید.

## اولین مشتری‌ها (صادقانه)

بخش رشد خودکار، یعنی نشان روی ویجت و لینک معرفی، **بعد از** این‌که چند مشتری داشته باشید به راه می‌افتد. برای ۱۰ تا ۲۰ مشتری اول:

- لینک «همکاری در فروش» (`/affiliate`) را برای طراح‌های سایت و آژانس‌ها بفرستید. آن‌ها از هر مشتری ۲۵٪ پورسانت ماهانه می‌گیرند و انگیزه دارند که بات را روی سایت مشتری‌هایشان نصب کنند.
- برای کسب‌وکارهایی که در سایتشان صفحه‌ی «سؤالات متداول» دارند پیام بفرستید و پیشنهاد نصب رایگان بدهید.
- در گروه‌ها و انجمن‌های وردپرس و فروشگاه‌داران معرفی‌اش کنید.
